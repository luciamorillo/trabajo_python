# 🌍 Análisis Geoespacial Exploratorio: Europa

> Proyecto inicial de desarrollo de portafolio enfocado en ingeniería de datos geoespaciales y visualización analítica.

## 📌 Descripción del Proyecto
Este repositorio contiene un flujo de trabajo analítico y espacial utilizando Python y librerías modernas de código abierto. El objetivo es procesar geometrías vectoriales del continente europeo y generar representaciones visuales limpias para el análisis territorial.

## 🛠️ Stack Tecnológico
- **Lenguaje:** Python 3.11
- **Entorno Virtual:** Conda (`geo_env`)
- **Librerías Clave:** 
  - `geopandas` (para la manipulación y análisis de datos vectoriales)
  - `matplotlib` (para la representación cartográfica)
- **Entorno de Desarrollo:** Positron IDE / Jupyter Notebooks
- **Control de Versiones:** Git & GitHub
